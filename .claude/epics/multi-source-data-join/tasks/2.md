# Task: Polars数据引擎集成和基础架构

## Description

将现有基于pandas的数据处理引擎替换为高性能的Polars引擎，建立新的数据处理基础架构。这是整个多源数据连接功能的基石，需要完整的Polars集成、基础配置管理和初步的数据源抽象层。

核心目标是建立一个性能优异、内存可控的数据处理引擎，为后续的多源连接、去重、时间对齐等高级功能奠定坚实基础。

## Acceptance Criteria

- [ ] Polars 0.20.x成功集成到后端项目，替换现有pandas依赖
- [ ] 建立DataEngine抽象层，支持基础数据操作（读取、筛选、聚合）
- [ ] 实现内存监控和护栏机制，确保内存使用不超过容器60%限制
- [ ] 建立配置管理系统，支持引擎参数和性能调优
- [ ] 分块处理机制实现，支持200K行/块的大数据集处理
- [ ] 性能基准测试：100万行数据操作 < 10秒
- [ ] 单元测试覆盖率 > 90%，包含内存和性能测试
- [ ] 向后兼容：现有API保持不变，内部实现切换到Polars

## Technical Details

### 实现方法和关键技术

**核心组件设计**：
- **DataEngine**: Polars引擎封装类，提供统一的数据操作接口
- **MemoryGuard**: 内存监控和保护机制，防止OOM
- **ChunkProcessor**: 大数据集分块处理器
- **ConfigManager**: 引擎配置和参数管理

**关键技术选择**：
- Polars 0.20.x：锁定版本避免API变更风险
- 懒计算模式：优化内存使用和计算性能
- Arrow格式：高效的内存布局和跨语言兼容
- 分块策略：基于内存使用动态调整块大小

### 涉及的代码位置/文件

```
backend/
├── core/
│   ├── data_engine.py         # Polars引擎封装
│   ├── memory_guard.py        # 内存监控和保护
│   ├── chunk_processor.py     # 分块处理器
│   └── config.py             # 配置管理
├── tests/
│   ├── test_data_engine.py
│   ├── test_memory_guard.py
│   └── test_performance.py
└── requirements.txt           # 添加Polars依赖
```

### 技术选型说明

1. **Polars vs pandas**：选择Polars因其10-100倍性能优势和更好的内存管理
2. **懒计算**：延迟执行优化复杂查询链
3. **Arrow内存格式**：零拷贝操作和列式存储优势
4. **分块处理**：平衡内存使用和处理效率
