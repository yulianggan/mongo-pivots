```typescript
interface ARTable {
  // 元数据信息
  metadata: {
    sourceInfo: DataSourceInfo[];

    createdAt: DateTime;
    version: string;
  };
  
  // 数据内容
  data: {
    columns: ColumnDefinition[];
    rows: DataRow[];
    indexes: IndexInfo[];
    partitions?: PartitionInfo[];

  // 透视配置
  pivotConfig: {
    allowedOperations: PivotOperation[];
    performanceHints: PerformanceHint[];
    limitations: Limitation[];
  };
}
```

### 性能优化策略

#### 1. 数据流优化
- **分块处理**: 大数据集自动分片处理，避免内存溢出
- **增量更新**: 支持数据源增量变更的增量透视更新
- **智能缓存**: 基于数据指纹的多层缓存策略
- **并行计算**: Polars并行处理 + Web Workers前端加速

#### 2. 用户体验优化
- **进度可视化**: 详细的处理阶段展示和时间预估
- **交互响应**: 长任务后台处理，界面保持响应
- **错误友好**: 智能错误诊断和修复建议
- **性能提示**: 实时性能监控和优化建议
