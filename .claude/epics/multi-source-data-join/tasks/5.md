# Task: Redis缓存系统和性能优化

## Description
实现基于Redis的缓存层和全面的性能优化机制，包括结果缓存、任务状态管理、内存护栏、分块处理和智能缓存策略。构建企业级性能保障体系，确保系统在大数据场景下稳定高效运行。

核心功能包括：
- Redis缓存集成，支持结果缓存和任务队列状态管理
- 智能缓存键生成，基于数据指纹和连接配置
- 内存护栏机制，防止OOM和资源泄漏
- 分块处理策略，支持大数据集的流式处理
- 任务队列管理，支持并发控制和优先级调度

## Acceptance Criteria
- [ ] Redis缓存系统完整集成，支持TTL=72小时
- [ ] 智能缓存键生成，基于Preset配置和数据指纹MD5
- [ ] 任务状态管理，支持pending/running/completed/failed状态
- [ ] 内存护栏实现，容器内存使用≤60%，硬上限8GB
- [ ] 分块处理机制，200K行/块，大数据集自动落地Parquet
- [ ] 任务队列控制，每用户并发≤2，队列深度≤5
- [ ] 缓存命中率监控，目标>70%
- [ ] 性能基准验证：相同配置二次执行<5秒

### 技术选型说明
- **Redis 6.0+**: 支持Streams和TTL，用于任务队列和缓存
- **Polars**: 内存高效的数据处理，天然支持分块
- **Parquet格式**: 大数据集持久化存储
- **psutil**: 系统资源监控
- **asyncio**: 异步任务处理
