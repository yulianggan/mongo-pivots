# Task: 连接向导UI和质量报告界面

## Description

基于React架构构建多源数据连接的核心用户界面，包括步骤式连接向导、实时质量报告仪表板和配置管理系统。这是用户与多源连接功能交互的主要入口，需要提供直观易用的操作流程和详尽的质量反馈。

核心组件包括数据源管理面板、字段映射配置器、连接预览器、实时进度跟踪和质量报告可视化。设计重点是降低学习成本，同时提供企业级的配置灵活性。

## Acceptance Criteria

- [ ] **连接向导完整流程** - 5步式向导支持从数据源选择到结果预览
- [ ] **数据源管理** - 支持拖放上传、预览、Schema自动识别
- [ ] **字段映射界面** - 可视化字段映射，支持数据类型转换和验证
- [ ] **连接配置器** - 支持多种连接类型、时间对齐、去重策略配置
- [ ] **实时进度跟踪** - SSE集成的进度条，支持任务取消和错误处理
- [ ] **质量报告仪表板** - 数据质量指标可视化，告警和建议展示
- [ ] **配置持久化** - Preset保存/加载，支持版本管理和共享
- [ ] **响应式设计** - 适配桌面和平板设备的布局

### 用户交互设计

#### 连接向导流程
1. **数据源选择**: 拖放上传或MongoDB配置
2. **字段映射**: 可视化字段关系建立  
3. **连接配置**: 连接类型、时间对齐、去重策略
4. **预览验证**: 小样本连接结果预览
5. **执行跟踪**: 实时进度和结果展示

#### 错误处理策略
- **输入验证**: 实时字段验证和错误提示
- **连接错误**: 友好的错误消息和修复建议
- **性能警告**: 大数据集连接的性能预警
- **兜底机制**: 网络错误的重试和降级处理
