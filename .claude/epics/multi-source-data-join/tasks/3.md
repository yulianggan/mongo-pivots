# Task: 多数据源连接器开发(Mongo/CSV/Excel)

## Description

基于已建立的Polars数据引擎，开发支持MongoDB、CSV、Excel三种主要数据源的连接器，实现统一的数据源抽象接口。每个连接器针对其数据源特性进行优化，支持流式读取、智能类型推断和性能优化。

核心目标是建立一套可扩展的数据源连接架构，为多源数据连接提供高性能的数据读取和预处理能力。

## Acceptance Criteria

- [ ] MongoConnector实现，支持aggregation pipeline优化和分页读取
- [ ] FileConnector实现，统一处理CSV/Excel文件，支持编码检测和流式解析
- [ ] SchemaInferencer智能类型推断，支持时间格式自动识别
- [ ] DataSourceRegistry数据源注册和管理系统
- [ ] 支持最大6个数据源同时连接和处理
- [ ] 性能要求：100万行CSV读取 < 15秒，MongoDB聚合查询 < 30秒
- [ ] 内存优化：流式处理避免全量加载，内存使用可控
- [ ] 错误处理：连接失败、格式错误、类型转换错误的友好处理

## Technical Details

### 实现方法和关键技术

**核心组件架构**：
```
DataSourceConnector (抽象基类)
├── MongoConnector
│   ├── AggregationOptimizer    # Pipeline优化器
│   ├── BatchReader            # 分批读取器
│   └── SchemaDetector         # MongoDB文档结构检测
├── FileConnector
│   ├── CSVProcessor           # CSV流式处理
│   ├── ExcelProcessor         # Excel转换处理
│   └── EncodingDetector       # 编码自动检测
└── SchemaInferencer
    ├── TypeDetector           # 数据类型推断
    ├── DateTimeParser         # 时间格式识别
    └── NullHandler            # 空值处理策略
```

**关键技术实现**：
- **MongoDB优化**：利用$project和$dateTrunc下推计算，减少数据传输
- **Excel处理**：xlsx2csv流式转换避免内存溢出
- **编码检测**：chardet自动识别CSV文件编码
- **懒加载**：支持数据预览而无需完整加载

### 技术选型说明

1. **连接器模式**：统一接口支持不同数据源，便于扩展

3. **Pipeline优化**：MongoDB查询下推提高性能
4. **智能推断**：减少用户配置负担，提升易用性
